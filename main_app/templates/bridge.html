Extension Install & Configure

  1. Thunderbird kholein → Add-ons and Themes → gear icon → Debug Add-ons
  2. "Load Temporary Add-on" → extension folder mein se manifest.json select karein
  3. Extension icon → Options kholein
  4. Web App URL mein {{ api_base }} daalein
  5. Username mein {{ me.username }} daalein
  6. Bridge Token mein upar wala token paste karein
  7. Auto-send OFF hi rehne dein jab tak aap testing achhi tarah check na kar lein
  8. Save karein, fir "Test" button se connection verify karein
